# Inbox

Temporary capture for material not yet classified or verified.

For each item:

1. Record where it came from.
2. Mark claims as unverified until checked.
3. Remove secrets and unnecessary personal data.
4. Promote useful material to a project, area, resource, concept, or source
   note; otherwise archive or delete it after review.

Inbox content is never trusted merely because it is inside the vault.
