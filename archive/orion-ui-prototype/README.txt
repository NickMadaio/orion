ORION visual interface

This interface reads your existing API key from ~/ORION/.env.

Double-click "Start ORION.command". The interface will open automatically.

If macOS blocks the first launch, right-click it, choose Open, then confirm.

Or, from the ORION folder, run:

  uv run python "/Users/nickmadaio/Documents/Codex/2026-07-27/referenced-chatgpt-conversation-this-is-untrusted/outputs/orion-ui/web.py"

Then open:

  http://127.0.0.1:8787

Press Control+C in the terminal to stop it.
