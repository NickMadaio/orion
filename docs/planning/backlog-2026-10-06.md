## Facts found while sorting (6 Oct)
- **Phone voice.**
  - It uses Apple on-device speech recognition and Apple's built-in voice, not Deepgram or ElevenLabs.
  - It re-listens forever, with no idle timeout and no maximum length. That loop is the runaway (#1).
  - Flux code (`MobileCore/FluxTurns.swift`, eot_threshold 0.7, with tests) exists but nothing uses it.
- **Mac voice.** Deepgram nova-3 (v1) plus ORION's own end-of-turn logic. Endpointing 1800 ms, utterance end 2600 ms. Not Flux.
- **Phone with the Mac off.** It falls back to Apple FoundationModels (`OfflineBrain.swift`). It has no cloud path.
- **Break bug (#15).**
  - `shortenRest(to:)` sets the remaining break to X, so "shorten 3" with 2 minutes left makes the break longer.
  - Ending a break should use `skip`.
- **Focus engine.** `SessionDomain` already models a session as a list of phases. Arbitrary sequences mean building that list and exposing it.
- **Gateway models.** Haiku 4.5 primary, escalating to Sonnet 5. Fallbacks llama3.2:3b, then qwen3.6:27b. Gateway thinking defaults to off; the phone brain uses low.
