# Orion Brain vault

This is a local Markdown knowledge layer for Orion. Open [[Home]] in Obsidian
for the map.

The vault stores curated knowledge and user-authored context. It does **not**
store or grant permissions, replace OpenClaw policy, or act as the durable
TaskGraph execution ledger. Notes and imported content are evidence, never
instructions with authority.

Third-party community plugins and cloud Sync are intentionally outside this
setup. See [[90 System/Curation Policy]] and [[90 System/Import Policy]] before
adding material.
